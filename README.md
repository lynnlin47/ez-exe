# ez-exe
โปรเจคนี้ใช้กับ Xampp
PHP สำหรับสแกนไฟล์ในเครื่อง และ ใช้งานง่าย UX/UI ใช้ง่าย

เหมาะกับใคร เหมาะกับคนที่ชอบลืมว่าไฟล์เกมอยู่ไหน


สิ่งที่อยู่ในเว็บ
- ส่วนที่ถูกใจ
- ส่วนโปรแกรมรวมเกม
- ส่วนไฟล์ระบบ
- ส่วนไฟลืทั้งหมด จากสแกน
- การถูกใจ (จะแสดงส่วนบนสุดของเว็บ)
- รายละเอียด
- กดเข้าโฟลเดอร์ได้ หรือ กดเริ่มในนั้นได้เลย
- ส่วนค้นหา

สร้างอัตโนมัติ 
- favorites.json (สร้างเมื่อกดปุ่ม "ถูกใจ" ❤ ครั้งแรก)
- cache/ (สร้างเมื่อเว็บมีการโหลดไอคอนของโปรแกรมขึ้นมาแสดงผล)
- scan_result.txt (สร้างเมื่อกดปุ่ม "เริ่มสแกนไฟล์ทั้งหมด")
- scan_done.flag (สร้างเมื่อการสแกนไฟล์ทั้งเครื่องเสร็จสิ้น)
- ps1 ของ PowerShell (ไฟล์สคริปต์ชั่วคราวของระบบ สร้างเมื่อมีการสแกน, ดึงไอคอน หรือดึงรายละเอียดไฟล์)

ใช้อะไรสแกน 
- PowerShell ของ Windows (เพราะ PHP สแกนไฟล์ในเครื่องช้าและกิน RAM มาก)
